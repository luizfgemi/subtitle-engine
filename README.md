# Subtitle Engine

FastAPI microservice for subtitle inspection, extraction, translation, Whisper GPU ASR, and Guardian orphan cleanup across the media stack.

## Development

Requires Python 3.12.

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements-dev.txt
./.venv/bin/pytest
```

Run service locally:

```bash
./.venv/bin/python -m app.main
```

## Endpoints

- `GET /health` - Healthcheck status and GPU Whisper readiness.
- `POST /api/v1/probe` - Inspect video audio and subtitle track streams.
- `POST /api/v1/generate` - On-demand subtitle pipeline execution for a media file.
- `POST /api/v1/event` - Tolerant webhook endpoint for Bazarr, Radarr, and Sonarr events.
- `POST /api/v1/batch-missing` - Process media files missing target subtitles from Bazarr DB.
- `POST /api/v1/guardian/audit` - Execute Guardian sync validation and orphan subtitle cleanup.

## Features & Background Scheduler

- **Pipeline**: `probe` -> `extract` -> local Ollama translation; falls back to Whisper `large-v3-turbo` with CUDA/VAD when no usable English subtitle can be extracted.
- **Validated local translation**: Uses `translategemma:12b` with its official prompt, translates marked contiguous batches, preserves SRT timing/styles, retries smaller batches, and atomically publishes only a fully validated result.
- **Safe failures**: A translation failure retains the extracted/transcribed English SRT for resume or diagnosis and never publishes it as a `pt-BR` subtitle.
- **Embedded satisfaction cache**: A full, non-commentary embedded target-language track satisfies the video without extraction. Its path, size, and modification time are cached locally and automatically invalidated when the video changes.
- **Self-contained provenance**: The first cue runs from `00:00:01,000` to `00:00:04,000` and identifies the model, Subtitle Engine version, and prompt ID; no neighboring metadata file can become orphaned when media is upgraded.
- **Guardian**: Audits Bazarr DB sync history and purges orphan `.srt` files (without matching video).
- **Background Scheduler**: Configurable via environment variables (`SCHEDULER_ENABLED`, `SCHEDULE_BATCH_MISSING_INTERVAL_MINUTES`, `SCHEDULE_GUARDIAN_INTERVAL_HOURS`).
- **Clean shutdown**: Scheduled batches honor cooperative cancellation between translation steps; daemon workers cannot keep the container alive during shutdown.

## Local translation

Ollama runs at `http://host.containers.internal:11434` and uses `translategemma:12b` by default.
The model must exist in the shared Ollama service before translation jobs start.
The exact runtime prompt and its evolution are documented in [`docs/prompt-history.md`](docs/prompt-history.md).

Relevant environment variables:

- `OLLAMA_URL`, `OLLAMA_MODEL`, `OLLAMA_KEEP_ALIVE`
- `TRANSLATION_BATCH_CUES`
- `TRANSLATION_RETRIES`, `TRANSLATION_RETRY_DELAY_SECONDS`, `TRANSLATION_TIMEOUT_SECONDS`
- `TRANSLATION_MAX_UNCHANGED_RATIO`

Find every subtitle generated by this service:

```bash
rg -l 'Tradução automática • modelo:' /movies /series -g '*.srt'
```

Audit generated subtitles against their embedded English tracks without changing media:

```bash
scripts/audit-generated-subtitles /movies /series
```

From a host without FFmpeg, use the running service container:

```bash
scripts/audit-generated-subtitles --container subtitle-engine /path/to/media
```

The audit discovers generated files by their embedded watermark and reports conservative
warnings for missing, unchanged, English, truncated, or repeated cues. Warnings require
review and never delete or replace a subtitle.
